# Learning Coach

An AI-powered mentor built with Azure AI Foundry that helps professionals transform learning into career growth.

## Vision

Learning Coach helps users:

- Create learning plans
- Track certifications
- Identify skill gaps
- Recommend projects
- Build GitHub portfolios
- Improve professional visibility
- Define next career steps
