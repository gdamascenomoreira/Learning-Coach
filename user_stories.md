# User Stories

## Story 1

As a learner

I want to define a career goal

So that Learning Coach can create a personalized learning roadmap.

---

## Story 2

As a learner

I want Learning Coach to identify my skill gaps

So that I can focus my study efforts.

---

## Story 3

As a learner

I want Learning Coach to recommend hands-on projects

So that I can gain practical experience.

---

## Story 4

As a learner

I want Learning Coach to recommend certifications

So that I can validate my skills.

---

## Story 5

As a learner

I want Learning Coach to suggest GitHub portfolio projects

So that I can demonstrate my skills publicly.
